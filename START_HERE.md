
## ✅ Step 2: Load Extension in Chrome (2 minutes)

1. Open Chrome
2. Go to: `chrome://extensions/`
3. Toggle **"Developer mode"** ON (top-right corner)
4. Click **"Load unpacked"** (top-left)
5. Select this folder
6. You should see the extension appear!

**Tip**: Click the puzzle icon (🧩) in Chrome toolbar and pin the extension.

---

## ✅ Step 3: First Use (2 minutes)

1. **Make sure you're logged into Instagram** (in any tab)
2. **Click Extension Icon**: Find it in your Chrome toolbar (from any tab!)
3. **Enter Username**: Your Instagram handle (without @)
4. **Select Schools**: Search and check 3-5 schools
5. **Choose Mode**: 
   - Mode 1 = analyze your network
   - Explore = browse suggested people
   - Test = test on single profile
6. **Click "Start Bot"**
7. **Bot auto-navigates** to Instagram if not already there!

## 🆘 Quick Troubleshooting

### Extension Won't Load
- Check all files are in folder (run `verify_installation.py`)
- Make sure Developer mode is enabled
- Try restarting Chrome

### Bot Won't Start
- Are you logged into Instagram?
- Are you on instagram.com?
- Did you enter your username?
- Did you select at least 1 school?

### No One Being Followed
- This is normal if matches are rare!
- Try selecting more schools
- Try different mode (Mode 1 vs Explore)
- Be patient - bot checks many profiles

### Bot Seems Stuck
- Wait 30 seconds (normal delay between profiles)
- Check Status field - does it say "Taking 1 hour break"?
- If truly stuck for 5+ minutes, click Stop Bot and restart

## ⏱️ Understanding Rate Limits

The bot has built-in delays for safety:

- **30 seconds** between each profile visit
- **1 hour break** after every 5 follows

This is **intentional** and **cannot be changed**.

Why? To protect your account from Instagram's spam detection.

**Daily Limits:**
- New accounts: ~20-50 follows/day
- Normal accounts: ~100-200 follows/day
- Established accounts: up to ~500 follows/day

## 🎯 Two Modes Explained

### Mode 1: Following → Followers
**Best for**: People in your extended network

**How it works**:
1. Gets list of people YOU follow
2. For each of them, gets THEIR followers
3. Visits those followers
4. Follows if they match your schools

**Pro**: Very targeted, friends-of-friends  
**Con**: Can take a while with large networks

### Explore Mode
**Best for**: Discovering new people

**How it works**:
1. Goes to Instagram's Explore People page
2. Gets suggested profiles
3. Visits each one
4. Follows if they match your schools

**Pro**: Fast, finds new people  
**Con**: Less targeted, more random

**Tip**: Try both modes to see which works better!

## 🚨 Warning Signs to Stop

If you see ANY of these on Instagram, stop immediately:

- "Action Blocked"
- "You're using this feature too fast"
- "We restrict certain activity"
- "Try again later"

**What to do**:
1. Stop the bot
2. Close Instagram
3. Wait 24-48 hours
4. Use Instagram manually for a day
5. Then try bot again (shorter sessions)
