# Quick Reference Card

## 🚀 Fast Start (30 Seconds)

1. Open extension → Enter Instagram username
2. Select 3-5 schools → Choose mode
3. Click "Start Bot" → Monitor stats

---

## 📊 Two Modes Explained

| Mode | What It Does | Best For |
|------|-------------|----------|
| **Mode 1** | Your following → Their followers | Targeted networking |
| **Explore** | Instagram's suggested people | Wide discovery |

---

## ⏱️ Rate Limits

- **30s** delay between profiles
- **1 hour** break after 5 follows
- **20-500** follows per day (varies by account age)

---

## 🎯 Status Messages Cheat Sheet

| Status | Meaning | Action Needed |
|--------|---------|---------------|
| Starting... | Initializing | None - wait |
| Visiting @user | Checking profile | None - normal |
| Followed @user | Success! | None - good |
| Taking 1 hour break... | Cooldown period | None - expected |
| Daily limit reached | Instagram blocked more | Stop for 24h |
| Stopped | Manually stopped | None |

---

## ✅ Pre-Flight Checklist

Before clicking "Start Bot":

- [ ] Logged into Instagram?
- [ ] On instagram.com?
- [ ] Username entered?
- [ ] Schools selected (3-10)?
- [ ] Mode chosen?

---

## 🔧 Quick Troubleshooting

| Problem | Solution |
|---------|----------|
| Bot won't start | Check login + reload page |
| No follows happening | Add more schools |
| Bot seems stuck | Wait 30s (normal delay) |
| Daily limit hit | Wait 24 hours |
| Extension crashed | Reload extension |

## 🎓 School Selection Strategy

### Conservative (Quality)
- Select 2-3 schools
- Your actual school + nearby
- Higher match accuracy

### Moderate (Balanced)  
- Select 5-8 schools
- Mix of local + national
- Good balance

### Aggressive (Quantity)
- Select 10-15 schools
- Broad geographic range
- More potential matches

---

## 🛡️ Safety Tips

### DO ✅
- Run 2-3 hour sessions
- Take breaks between runs
- Mix with manual Instagram use
- Post regular content
- Engage with new followers

### DON'T ❌
- Run 24/7
- Use brand new accounts
- Modify rate limits
- Ignore Instagram warnings
- Use multiple bots simultaneously

## 📊 Statistics Explained

**Profiles Visited**
- Total profiles checked
- Includes matches and non-matches
- Does not include already-following

**Followed**
- Successful follow actions
- Only profiles matching school criteria
- Excludes already-following

**Status**
- Real-time bot activity
- Updates every action
- Shows current profile being processed

## ⚠️ Warning Signs

Stop immediately if you see:

- "Action Blocked" on Instagram
- "You're using this feature too fast"
- "We restrict certain activity"
- Unusual Instagram pop-ups

Then:
1. Stop bot
2. Close Instagram  
3. Wait 24-48 hours
4. Resume carefully
